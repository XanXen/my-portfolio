Tech Highlights
01
Custom Cursor System
CSSJavaScriptmix-blend-mode

双圆跟随光标，使用线性插值（lerp）实现弹簧物理跟随效果。外圈通过 mix-blend-mode: difference 实现反色效果，在深色/浅色背景上自动切换对比色，hover 交互元素时缩放变形。

Move your mouse here
02
3D Model Loading
Three.jsGLTFLoaderWebGL

基于 Three.js 加载 GLTF 3D 模型，配置环境光 + 聚光灯 + 平行光 + 点光源的多光源系统。模型跟随鼠标位置实时旋转，带有插值平滑过渡。通过 ResizeObserver 实现画布自适应缩放，加载过程带有实时进度条。

03
Hand Gesture Recognition
MediaPipeCanvasSpring Physics

接入 Google MediaPipe 手势识别，将手部关键点映射为屏幕光标位置。光标运动使用弹簧阻尼物理模型（K=0.28, damping=0.72），实现自然的跟随手感。配合 Canvas 粒子系统，手势划过时生成交互粒子效果。支持握拳手势检测触发特定操作。

04
Cross-iframe Communication
postMessageiframeEvent Forwarding

Plant Sense Party 项目使用透明 overlay 层捕获主页面的鼠标事件，通过 postMessage API 将光标坐标和交互状态实时转发给 iframe 内的 p5.js 画布，实现光标穿透 iframe 边界的无缝交互体验。

05
Page Transitions
CSSopacityFixed Positioning

页面切换使用纯 opacity 渐隐渐显动画，刻意避免 transform 属性——因为 CSS transform 会创建新的 containing block，导致 fixed 定位元素（如导航栏、光标）相对于变换元素定位而非视口，产生布局错乱。

06
Coze Agent Integration
Coze APISSE PollingFile Upload

本页面的 4 个 AI Agent 均通过 Coze API 实时对话。采用轮询机制（2s 间隔，最长 120s）等待异步回复，支持文件上传后附带 file_id 发送。工作流类 Agent 使用 SSE 流式接口，前端解析多种返回格式（message/content/data/output）确保兼容性。

07
Rotating Circular Text
CSS TransformScroll EventRGB Manipulation

环形排列文字通过逐字符计算旋转角度实现。滚动时实时计算 RGB 值，文字颜色从白色渐变为灰色，营造层次感。配合 CSS 持续旋转动画，形成动态视觉焦点。
